# 概要
- Steam版のぷよぷよeスポーツで動作するぷよぷよAIです。

## 事前準備
- 仮想コントローラを使用するために、Scarlet.Crush氏によって開発されたSCP Virtual Bus Driverのインストールが必要です。

## 使い方
- Gamepadの [Index] を選択した上で [Connect] を押し、amaを仮想コントローラに接続します。
	- [Index] は [Player] と対応している必要はありません。
- 対戦するには、[Vs] にチェックを入れ、[Player] をP1またはP2に設定してください。
- その他の設定については、下記「設定項目」をご参照ください。

# 設定項目
## Overlay
- ストリーミング用のオーバーレイを表示します

## Gamepad
- [Index]: 仮想コントローラのインデックス
	- amaを複数起動したい場合、異なる [Index] を使用してください。
- [Connect]: amaを仮想コントローラに接続します
- [Disconnect]: amaに接続されている仮想コントローラを切断します
- キーボード上で以下のキーを押すことで、仮想コントローラを操作できます：
	- [1]: 上キー
	- [2]: 下キー
	- [3]: 左キー
	- [4]: 右キー
	- [A]: Aボタン

## Game
- [Vs]: 対戦モードか否か
- [Player]: （対戦モードの場合）amaがどちらの盤面を操作すべきか

## AI
- [Speed]: 操作速度
- [Cancel]: キャンセル
- [Chain]: 最大連鎖数
- [Attack]: 攻撃のスタイル
	- [LV0]: 攻撃しない
	- [LV1]: 弱めの攻撃モード
	- [LV2]: 最強の攻撃モード
- [Defense]: 対応のスタイル
	- [LV1]: 弱めの対応モード
	- [LV2]: 最強の対応モード
