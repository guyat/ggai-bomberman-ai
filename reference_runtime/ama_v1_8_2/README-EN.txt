# Overview
- Puyo Puyo AI for Puyo Puyo Champions on Steam.

## Requirement
- This requires Scarlet.Crush's SCP Virtual Bus Driver to create a virtual controller. Make sure you install it.

## Basic usage
- Select a gamepad index and press [Connect] to connect to a virtual gamepad.
- Toggle [VS] to enable/disable PVP mode.
- Change [Player] if PVP mode is on.
- Configure ama's settings.
- Enjoy.

# Details
## Overlay
- Show overlay for streaming.

## Gamepad
- [Index]: Select virtual gamepad index.
- [Connect]: Press to connect to a virtual gamepad.
- [Disconnect]: Press to unplug the virtual gamepad.
- The following keyboard keys can be pressed to simulate gamepad inputs:
	- [1]: UP
	- [2]: DOWN
	- [3]: LEFT
	- [4]: RIGHT
	- [A]: A
- If multiple ama.exe are running at the same time, please don't connect to the same gamepad index.

## Game
- [Vs]: Toggle VS mode. Enable if you want ama to play PVP.
- [Player]: Select the player.

## AI
- [Speed]: Change ama's speed.
- [Cancel]: Toggle movement cancelation.
- [Chain]: Change ama's maximum chain.
- [Attack]: Change ama's attacking style:
	- [LV0]: No attacking.
	- [LV1]: Weak attacking mode.
	- [LV2]: The strongest attacking mode.
- [Defense]: Change ama's defense style:
	- [LV1]: Weak defense mode.
	- [LV2]: The strongest defense mode.
